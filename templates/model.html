About the model

How the AQI predictor was built and how well it works.

What it does

A Random Forest regression model estimates AQI from 11 pollutant measurements (PM2.5, PM10, NO, NO₂, NOx, NH₃, CO, SO₂, O₃, benzene, toluene). It was trained on {{ '{:,}'.format(m.train_rows + m.test_rows) }} daily observations from the city-level and station-level files together. Missing pollutant values are filled with the training-set median.

It estimates the AQI for the readings you give it. It does not forecast tomorrow's AQI.

Limitations

  • AQI is calculated from pollutant levels, so this is estimation, not future forecasting.
  • Data ends {{ meta.date_to }}; the site shows history, not live air quality.
  • Missing values are filled with medians, which can hide local patterns.
  • Extreme AQI values strongly affect MSE and RMSE.
  • Not a replacement for official CPCB readings.
